# Metro Route

Сервис построения маршрутов в московском метро с двумя интерфейсами:
Telegram-бот и HTTP-сервер.

## Что реализовано

- **Ядро на графе метро.** Дейкстра с двумя режимами оптимизации: по времени и по числу пересадок. При равенстве времени выбирается маршрут с меньшим числом пересадок (и наоборот). Время пересадок учитывается отдельно от времени перегонов.
- **Детализация маршрута.** Путь разбивается на сегменты по линиям, пересадки выделены отдельно.
- **Два интерфейса поверх одного ядра.** Telegram-бот (сценарий с поиском станций и кнопками) и HTTP API (`POST /route`, `GET /stations`, `GET /history/{user_id}`, `GET /healthz`). Ядро не зависит от интерфейса.
- **История запросов в PostgreSQL.** Каждый успешный маршрут сохраняется (пользователь, откуда, куда, режим, время). В боте - команда `/history`, в API - `GET /history/{user_id}`.
- **Тесты.** Юнит-тесты, интеграционные на реальном `metro.json`, тесты всех эндпоинтов API, интеграционные тесты БД (пропускаются без `TEST_DATABASE_URL`).
- **Инфраструктура.** Структурированное логирование (`log/slog`) с уровнями, корректное завершение по сигналу (текущие запросы дорабатывают), ограничение параллелизма через пул токенов, Docker Compose для Postgres + API + бота.

## Быстрый старт

Требования: Go 1.27+, Docker Compose.

```bash
# 1. Создать файл .env и указать
# BOT_TOKEN=...       - токен Telegram-бота от @BotFather
# LOG_LEVEL=...     - вариант вывода логов (info/debug) (по умолчанию info)
# DATABASE_URL=postgres://metro:metro@localhost:5433/metro-db?sslmode=disable - cтрока подключения к Postgres
# TEST_DATABASE_URL=... - строка подключения к тестируемой БД (может совпадать с DATABASE_URL)
# HTTP_ADDR=... - адрес HTTP-сервера (по умолчанию :8080)

# 2. Поднять Postgres
make up

# 3. Запустить HTTP-сервер (Postgres + API)
make run-api
# или Telegram-бота (Postgres + бот)
make run-bot

# 4. Для прекращения работы программы
# Ctrl+C в терминале, где запущен run-api / run-bot - корректное завершение
make down      # остановить контейнеры

# Для более подробной информации о тестировании, сборке, запуске в Docker
make help
```

```text
metro-route/
├── cmd/
│   ├── api/
│   │   └── main.go                  # точка входа HTTP-сервера
│   └── bot/
│       └── main.go                  # точка входа Telegram-бота
├── internal/
│   ├── models/
│   │   └── models.go                # доменные типы: Station, Graph, Route,
│   │                                # RouteMode
│   ├── storage/
│   │   ├── schema.go                # чтение и парсинг data/metro.json
│   │   ├── graph.go                 # построение графа в памяти
│   │   ├── requests.go              # работа с историей запросов в Postgres:
│   │   │                            # сохранение маршрута и выборка последних
│   │   │                            # запросов пользователя
│   │   └── db_setup.go              # применение SQL-скрипта при старте
│   │                                # в одной транзакции
│   ├── router/
│   │   └── dijkstra.go              # поиск кратчайшего пути алгоритмом Дейкстры
│   │                                # с двумя режимами оптимизации и разбивкой
│   │                                # пути на сегменты по линиям
│   ├── api/
│   │   ├── handler.go               # HTTP-хендлеры: POST /route, GET /stations,
│   │   │                            # GET /history/{user_id}, GET /healthz
│   │   ├── contracts.go             # структуры запросов и ответов API
│   │   ├── respond.go               # единый формат JSON-ответов и ошибок
│   │   └── middleware.go            # логирование запросов, восстановление после
│   │                                # паники, идентификация пользователя (условная)
│   └── telegram/
│       ├── handler.go               # сценарий бота: команды, поиск станций,
│       │                            # выбор режима, построение маршрута,
│       │                            # клавиатуры и уведомления
│       └── state.go                 # состояние диалога с пользователем
├── data/
│   ├── metro.json                   # схема метро: 4 линии, 70 станций,
│   │                                # 67 перегонов, 9 пересадок
│   └── script.sql                   # SQL-скрипт: таблица requests + индекс
├── compose.yaml                     # postgres + api + bot (профили api/bot)
├── Makefile
└── go.mod
